# Wannyam Terkuma Benedict — Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript, with a dark-first visual style, optional light theme, animated role line and scroll reveals.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. The résumé is available at `resume.html`; its **Print / Save as PDF** button opens the browser print dialog.

## Files

- `index.html` — portfolio landing page and experience sections
- `resume.html` — printable résumé
- `styles.css` — responsive visual styles and motion
- `portfolio-inspired.css` — portfolio theme, dark/light modes, pill navigation and motion styling
- `script.js` — mobile navigation and scroll reveal
- `assets/` — supplied portrait and project/context screenshots
- `projects/field-data-quality-workbench/` — a local-first, synthetic-data CSV review demo
- `PROJECT-ROADMAP.md` — proposed next projects, separated from completed work

The page uses Google Fonts when network access is available and falls back to system serif/sans-serif fonts otherwise.

The Ngosue International School project links to its live public website at [nisaliade.netlify.app](https://nisaliade.netlify.app/). Proposed next projects are tracked in `PROJECT-ROADMAP.md`; the current visual direction is documented in `DESIGN.md`.
